### §11-10 匯出 → 清除護照 → 匯入還原 → 33 格全部回來 ✅

**這一條是用滿載的護照做的，不是幾格意思意思。**

1. 把 33 格全部蓋滿，其中 32 格附照片。照片不是佔位小圖，是 900×600 的雜訊圖，
   壓縮後**平均每張 138 KB** —— 刻意逼近真實手機照片，因為這條驗收真正的風險是
   payload 大小，用 160 bytes 的測試圖等於沒測
2. 匯出：檔名 `bt-passport-BT0441039-2026-08-18.json`，**4.34 MB**，
   33 章／33 則心得／32 張照片／大頭照 39 KB
3. 清除這本護照 → SQL 確認 stamps=0、entries=0、name_zh=null、avatar=null
4. 匯入那個 4.34 MB 的檔案 → **8.5 秒完成**，toast「還原了 33 個章。」
5. 比對：重新匯出一次，與原始備份做逐格指紋比對
   （act_id｜日期｜心得｜照片位元組數）→ **33 格完全相同，差異 0 格**
   護照資料、大頭照 39 KB 一併回來
6. SQL 確認：stamps=33、entries=33、有照片 32、照片總計 4400 kB、avatar 40351 bytes

### §11-17 prefers-reduced-motion 下動畫關閉 ❌→✅（原本沒過，已修）

**第一次驗收沒有通過。**

用 CSSOM 逐條比對「有 animation 的選擇器」與「reduced-motion 區塊關掉的選擇器」：

- 有動畫：`.page.turn`、`.stamp.land`、`.overprint.land`
- 有關掉：`.page.turn`、`.stamp.land`
- **沒關掉：`.overprint.land`**

`.overprint.land` 是蓋滿 33 格時「FULL」浮水印的彈跳動畫，跟 `.stamp.land` 共用同一組
`land` keyframe。它會漏掉的原因很具體：**它只在集滿的那一刻出現，平常根本測不到** ——
開發與測試過程中沒有人的護照是滿的。

修正：`index.html` 的 reduced-motion 規則加入 `.overprint.land`，並在該處留下註解
說明新增動畫時要回來加。重驗：「沒有被關掉的」為空陣列。

這一條也是為什麼「不接受看起來沒問題」寫在 spec 裡 —— 眼睛看不出來，
因為要看到它得先蓋滿 33 格。

備註：頁面另有三處 0.15–0.16 秒的 `transition`（按鈕與輸入框的顏色、邊框、透明度變化）。
它們不在 reduced-motion 規則內。判斷是不需要處理：那是顏色淡入，不是位移或縮放，
不屬於會引發前庭不適的動態。若日後有人認為要一併關閉，這是一個明確的選擇而不是遺漏。

### §11-19 斷開 Supabase 連線，前端顯示休眠訊息而非空白畫面 ✅

把 `src/config.js` 的 URL 改成不存在的專案後重整（本機；正式站台不做破壞性測試）：

  beyondtaiwan2020@gmail.com 請人恢復。」

- 有「再試一次」可以按

jsdom 另有四個情境覆蓋：`down`（查詢失敗）、`slowboot`（等太久要換句話說）、
`deadnet`（連 auth 都連不上 → 休眠頁）、`expired`（session 過期 → 登入頁，不可誤報成休眠）。
